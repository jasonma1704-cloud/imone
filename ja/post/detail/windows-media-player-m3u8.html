Windows Media PlayerでM3U8を再生する

Windows Media PlayerはWindowsシステムのデフォルトプレーヤーです。M3U8およびHLSストリームのネイティブサポートは限られています。

ネイティブサポートの状況

内蔵プレーヤーはM3U8リンクを直接解析することはできません。主にWMV、MP3、MP4などの従来のローカルメディア形式に焦点を当てています。

ソリューション

サードパーティのデコーディングプラグインをインストールするか、Windows Media Playerにインポートする前にM3U8を標準のMP4ファイルに変換することができます。

使用の提案

頻繁にM3U8を再生する場合は、互換性を高めるために専用のストリーミングプレーヤーまたは当社のオンラインプレーヤーを使用することをお勧めします。
