使用方法

  1. 1. ビデオまたはオーディオのURLを入力します（m3u8 / mp4 / ts / mp3 などに対応）。
  2. 2. M3U8のダウンロード、MP4への変換、音声抽出など、コマンドの用途を選択します。
  3. 3. 必要に応じて、Referer、User-Agent、Cookie、またはプロキシを入力します。
  4. 4. 「コマンド生成」をクリックし、コピーしてローカルのターミナルで実行します。
ヒント：ソースサイトに認証制限がある場合は、通常Referer、Cookie、またはUser-Agentを含める必要があります。そうしないと、FFmpegが403 / 401 / Forbiddenエラーを返します。

なぜFFmpegのダウンロードが失敗するのですか？

          
最も一般的な理由は、配信元のサイトがReferer、Cookie、またはUser-Agentによってアクセスを制限しているか、プロキシを必要としているためです。これらのヘッダーを含めることで通常は解決します。

        

        

          
どのような時に「copy」を使用すべきですか？

          
元のストリームがすでにH.264/AACである場合は、無劣化でコンテナを入れ替える（Remux）ために-c copyを使用することをお勧めします。処理が非常に高速で、再圧縮による画質・音質の劣化がありません。

        

        

          
どのような時にトランスコード（再エンコード）すべきですか？

          
再生機器との互換性が悪い場合、動画や音声のコーデック規格が非標準である場合、あるいはファイルサイズを圧縮したい（またはビットレートを変更したい）場合は、H.264 + AACにトランスコードするコマンドを使用するのが安全です。
