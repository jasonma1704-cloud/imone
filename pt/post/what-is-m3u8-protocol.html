O Que É o Protocolo M3U8?

M3U8 é uma parte fundamental do HTTP Live Streaming (HLS). É um formato de lista de reprodução baseado em texto usado para indexar e descrever mídia de streaming. Um arquivo M3U8 é texto simples em codificação UTF-8 — uma extensão do formato M3U clássico.

M3U8 não contém dados de mídia reais. Em vez disso, ele lista URLs de segmentos de mídia — normalmente arquivos MPEG-2 TS ou fragmentos fMP4. O player lê a lista de reprodução, baixa os segmentos em ordem e os reproduz como um fluxo contínuo.

M3U8 é amplamente usado para VOD e streaming ao vivo. Ele suporta streaming de taxa de bits adaptável (ABR), para que os players possam alternar a qualidade com base nas condições da rede para uma melhor experiência.

Estrutura do Arquivo M3U8

Um arquivo M3U8 típico começa com #EXTM3U, seguido por tags e entradas de segmentos. Por exemplo: 

#EXTM3U
#EXT-X-VERSION:3
#EXT-X-TARGETDURATION:10
#EXTINF:10.0,
segment1.ts
#EXTINF:10.0,
segment2.ts
#EXT-X-ENDLIST

Este formato tornou o M3U8 um padrão para o streaming moderno, adotado pelas principais plataformas de vídeo do mundo.
