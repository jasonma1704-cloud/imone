Estrutura do Arquivo M3U8

M3U8 é um arquivo de texto simples composto por tags e links de recursos. Diferentes tags definem regras de reprodução, informações de segmentos e atributos de fluxo.

Tag de Cabeçalho Básica

#EXTM3U é a tag de cabeçalho obrigatória, marcando que este é um arquivo de playlist M3U8 padrão. Todos os arquivos M3U8 válidos devem começar com esta tag.

Tag de Duração do Segmento

#EXTINF é usado para registrar a duração de reprodução de um único segmento TS, seguido pelo URL real ou caminho relativo do arquivo de segmento de vídeo.

Tags de Atributos Estendidos

Existem também tags para definir resolução, taxa de bits, informações de criptografia e marcadores de transmissão ao vivo. Essas tags realizam funções avançadas, como troca de múltiplas definições e reprodução criptografada.

Classificação de Arquivos

Os arquivos M3U8 são divididos em playlist mestre e playlist de mídia. A playlist mestre é usada para seleção de múltiplas taxas de bits, enquanto a playlist de mídia gerencia diretamente os segmentos de vídeo.
