What is HLS

HLS stands for HTTP Live Streaming, a streaming media protocol developed by Apple for network live and on-demand video.

Basic Principle

HLS splits the whole video into small TS media segments, and uses M3U8 text files to manage segment addresses and playback order.

Protocol Features

Based on standard HTTP protocol, it can pass through most firewalls and proxies, and supports adaptive bitrate according to network quality.

Main Application

HLS is the most widely used streaming protocol on web pages, mobile devices and smart TVs, covering video websites and live broadcast platforms.
