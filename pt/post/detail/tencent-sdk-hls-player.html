Tencent SDK HLS Player

Tencent HLS Player SDK is a professional web playback component built for HLS and M3U8 streaming media. It is widely used in video on demand and live streaming services.

Core Capabilities

It supports standard HLS streams, encrypted M3U8 sources, multi-resolution switching and automatic reconnection when network interrupts.

Development Features

The SDK provides rich API interfaces, allowing developers to customize player style, control playback logic and monitor stream status.

Application Scenarios

It is suitable for official websites, web apps and mobile H5 pages, delivering stable and smooth playback experience for massive users.
