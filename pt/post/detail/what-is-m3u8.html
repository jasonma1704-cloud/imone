O que é M3U8

M3U8 é um arquivo de lista de reprodução codificado em UTF-8, que é o formato de arquivo principal do protocolo de streaming HLS. Ele não contém dados de vídeo reais.

Natureza do Arquivo

É um arquivo de texto puro que registra o caminho, a duração e os atributos de cada segmento de vídeo, atuando como um guia de índice para a reprodução.

Tipos de Arquivo

O M3U8 é dividido em lista de reprodução ao vivo e lista de reprodução sob demanda. Os arquivos ao vivo são atualizados dinamicamente, enquanto os arquivos sob demanda são fixos.

Cenários de Uso

Quase todos os vídeos sob demanda e transmissões ao vivo na web usam links M3U8. É o formato padrão para a transmissão de vídeo em rede moderna.
