M3U8Player is a Chrome extension for HLS client playback. It supports .m3u8 HTTP Live Streaming (HLS). Built on HTML5 Video and Media Source Extensions. It converts MPEG-2 TS and AAC/MP3 streams into ISO BMFF (MP4) fragments. Uses Web Worker for async transcoding if available. Also supports HLS + fmp4.

What is M3U8?

M3U8 is a UTF-8 encoded plain text playlist format. It does not store video/audio data itself, only records media resource URLs for players to load streaming content.

Widely used in online radio, local media playlist management. You can batch play media via M3U8 without opening files one by one.

It supports absolute/relative paths and network URLs, with comment notes. Originally for audio playlists, now widely used in web video and live streaming.

How to Open M3U8 File?

You can open M3U8 with any text editor to view raw links, but text editors cannot play video directly.

Use professional players like VLC, iTunes, XMMS (Linux), CocoModX (Mac) for normal playback.

You can also use online M3U8 players to stream directly. Note: online tools only support network M3U8 URLs, not local files.

FAQ

What is M3U8 Protocol?

HLS streaming index protocol for web video distribution.

How to Play M3U8 Video?

Use stream-supported players, browsers or online tools.

M3U8 Format Advantages

Segmented loading, low lag, mobile compatible, adaptive bitrate, easy anti-leech.

M3U8 vs Normal Video Formats

M3U8 is only a list of segments; MP4 is a single complete video file.

Common Video Formats

MP4, FLV, MOV, AVI, MKV, WM V, WebM etc.

M3U8 Live Streaming Usage

Live stream sliced in real time, client loads segments continuously for low-latency playback.

M3U8 Working Principle

Video split into small TS chunks; M3U8 records order and URLs for sequential loading.

How to Parse M3U8

Read index text via code/tools, extract segment links and merge into full video.
