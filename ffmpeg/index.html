Why is FFmpeg failing to download?

          
The most common reason is that the source site restricts access via Referer, Cookie, or User-Agent, or requires a proxy. Including these headers usually resolves the issue.

        

        

          
When should I use "copy"?

          
If the original stream is already H.264/AAC, using -c copy for lossless remuxing is recommended. It's faster and avoids quality degradation from re-compression.

        

        

          
When should I transcode?

          
Transcoding with H.264 + AAC commands is safer when player compatibility is poor, audio/video encoding is non-standard, or you want to compress the file size/change the bitrate.
