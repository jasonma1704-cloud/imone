M3U8 转 MP4

输入 m3u8 视频链接，纯前端一键转换为 MP4 文件。仅支持 CORS 允许的 m3u8，适合短视频处理和下载。

转换步骤说明

  1. 输入 m3u8 视频链接，点击“开始转换”。
  2. 工具自动下载 m3u8 文件并解析 ts 分片。
  3. 依次下载所有 ts 分片（需支持 CORS）。
  4. 在浏览器内拼接分片并转为 MP4 文件。
  5. 转换完成后自动下载 MP4 文件到本地。
注：仅适合短视频，且 m3u8/ts 需允许跨域访问。

使用说明

该工具基于浏览器前端实现，无需安装任何软件。请确保 m3u8 地址可直接访问，并且 ts 分片允许跨域，否则转换过程会失败。

适用场景

适合短视频、演示片段、测试流等快速转换。大文件或长时间直播流可能会因浏览器内存、网络和跨域限制导致转换失败。
