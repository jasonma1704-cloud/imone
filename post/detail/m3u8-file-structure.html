M3U8 File Structure

M3U8 is a plain text file composed of tags and resource links. Different tags define playback rules, segment information and stream attributes.

Basic Header Tag

#EXTM3U is the mandatory header tag, marking that this is a standard M3U8 playlist file. All valid M3U8 files must start with this tag.

Segment Duration Tag

#EXTINF is used to record the playing duration of a single TS segment, followed by the actual URL or relative path of the video segment file.

Extended Attribute Tags

There are also tags for defining resolution, bitrate, encryption information and live stream markers. These tags realize advanced functions such as multi-definition switching and encrypted playback.

File Classification

M3U8 files are divided into master playlist and media playlist. The master playlist is used for multi-bitrate selection, while the media playlist directly manages video segments.
