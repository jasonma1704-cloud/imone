什么是 M3U8？

        

          

            M3U8 是 HLS（HTTP Live Streaming）协议中的播放列表格式，广泛用于在线视频、直播流媒体、OTT、CDN 视频分发等场景。
          

          
HLS 播放列表通常包含：

          
    
            
  • 媒体分片（TS / fMP4）
    • 
            
  • 多码率主播放列表
    • 
            
  • AES-128 加密信息
    • 
            
  • EXTINF 时长标签
    • 
            
  • 直播流元数据
    • 
          

          
本工具用于开发测试、播放器调试、HLS 流媒体分析。
